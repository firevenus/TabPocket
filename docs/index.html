TabPocket页袋

Tabs, bookmarks and browsing time — all kept on your own machine.

A local-first browser extension for people who keep 60 tabs open. Collapse them into a session, clean up the bookmarks you never open, and see where the hours actually went. No account. No server. No tracking.

View on GitHub Privacy policy

What it does

  • Tab sessions Collapse a whole window into one saved session, then restore it later — titles, order and URLs intact.
  • Bookmarks without the mess Bring native bookmarks and your own saved items into one list, then sort them by how often you actually visit them.
  • Bookmark audit See which bookmarks you have not touched in a year, by page or by site, and export the result as CSV.
  • Browsing statistics Foreground time per domain and per hour, aggregated in IndexedDB so the chart stays fast however long you use it.

How it handles your data

Everything is stored in your own browser profile — chrome.storage.local and IndexedDB. There is no backend to send it to: no analytics, no telemetry, no advertising SDK, no remote code. Uninstalling the extension deletes its data.

标签、收藏与浏览时长，全部留在你自己电脑上。

给同时开六十个标签页的人做的本地扩展。把一窗标签收拢成一个会话，清掉那些收藏之后就再没打开过的书签，再看看时间到底花在了哪。没有账号、没有服务器、不做追踪。

功能

  • 标签会话 把整个窗口收拢成一个会话，之后一键恢复，标题、顺序、网址都不变。
  • 收藏整理 把浏览器原生书签和扩展内收藏汇到一处，可按真实访问频次排序。
  • 收藏体检 找出一年没打开过的书签，按页面或按网站两个视角看，结果可导出 CSV。
  • 浏览统计 按域名与小时聚合前台停留时长，数据存 IndexedDB，用多久都不会越算越慢。

数据怎么处理

数据只存在你自己的浏览器里（chrome.storage.local 与 IndexedDB）。扩展没有后端可以上传：无统计分析、无遥测、无广告 SDK、无远程代码。卸载即删除本地数据。
