--------------------------------------------------------------------------------
  "网络记录" is Chrome's Chinese label for Web history, described as
  "用户访问过的网页及相关数据（例如网页标题和访问时间）的列表". We read
  history for visit counts, so this one is mandatory. Do not go looking for a
  checkbox literally named "Web history" in the Chinese UI — it is not there.

  "用户活动" is the category the idle permission falls into. Its Chinese help
  text lists "网络监控、点击、鼠标指针位置、滚屏或击键操作记录" — we do none of
  those, only read an idle/active state — but the category is still the right
  one, and the declaration is checked against the manifest. Untick it while
  shipping idle and the submission is false.

  Do NOT tick 网站内容: no host_permissions, no content_scripts, no DOM access.
