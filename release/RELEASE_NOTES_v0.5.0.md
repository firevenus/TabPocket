# TabPocket v0.5.0 — 收藏体检

> 本地试用版，尚未推送到 GitHub Release。

## 新增：收藏体检

入口：弹窗 →「收藏」页签 → **收藏体检** 按钮（绿框），在新标签页打开完整页面。

它做的事：

1. 读取浏览器**全部原生书签**（递归所有文件夹，自动去重，剔除非 http(s) 的条目）
2. 对每个书签 URL 用 `history.getVisits` **逐条统计区间内的访问次数**
   - 支持近 30 天 / 近 90 天 / 近 1 年切换
   - 自动兼容「结尾斜杠」与「`#` 锚点」差异的 URL
   - 不使用 `history.search` 的 `visitCount`，因为那是全量累计值，分不出区间
3. 按访问频次排行，同时给出两个视角：
   - **按页面**：哪一篇收藏最常被打开
   - **按网站**：哪个站点在你的收藏里最活跃（含收藏页面数）
4. 概览 KPI：收藏页面数 / 区间内访问过 / 区间内没碰过 / 区间总访问次数
5. 排序：访问次数、最近访问、收藏时间（按网站视角为收藏页面数）
6. 筛选：「有访问」/「没访问」+ 标题 / 网址 / 文件夹搜索
7. 每条可点开、可从浏览器书签里删除（二次确认，不可撤销）、可导出 CSV（带 BOM，Excel 直接识别中文）

## 其它

- 结果缓存到 `storage.local`，重开页面秒出；点「重新扫描」可强制重算
- 新增独立入口 `audit.html`，与 `stats.html` 一样按需加载（体检页 11.9 kB，不影响弹窗体积）
- 新增配置项无需额外权限：只用已有的 `bookmarks` + `history`
- 新增自测脚本 `scripts/selftest-audit.mjs`（mock 浏览器 API，`node scripts/selftest-audit.mjs`，17 项断言）

## 安装 / 更新

1. 解压 `TabPocket-v0.5.0-edge.zip`
2. `edge://extensions` → 开发人员模式 → 「加载解压缩的扩展」→ 选解压出的文件夹
   （已装旧版则先点旧卡片上的「重新加载」，再把目录指向新解压的文件夹）

## 已知限制

- 浏览器关闭「记录浏览历史」时，所有访问次数都会是 0
- 书签特别多（>3000）时首次扫描需要十几秒，期间有进度条
- 浏览器自己导出的 `chrome://bookmarks` 里删除是不可撤销的，插件只做确认提示
