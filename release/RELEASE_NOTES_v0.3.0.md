## TabPocket · 页袋 v0.3.0

> 把网页收进口袋，需要时再掏出来。

第一个可安装的版本。Manifest V3，数据 100% 本地，无需账号，MIT 开源。

### 本版功能

**标签收拢（OneTab 式）**
- 一键收拢当前窗口全部标签成会话，跳过固定页和浏览器内部页
- 会话自动命名，支持恢复、删除、双击重命名
- 展开会话查看单个标签，点一下单独打开

**收藏 + 一键整理（Raindrop 式）**
- 收藏当前页 / 右键菜单收藏
- 标题、网址、标签实时搜索 + 标签筛选
- 一键整理浏览器原生收藏：自动分类 + 高频网站标记「常用」
- 导出 / 导入 JSON 备份

**待看（稍后阅读）**
- 「加入待看」随手丢进口袋，看完一键移出
- 复用标签体系，搜索、备份、整理全自动兼容

**关于**
- 版本号、GitHub 仓库地址、反馈入口

### 安装（Edge / Chrome）

1. 下载下方 `TabPocket-v0.3.0-edge.zip` 并解压
2. 打开 `edge://extensions` 或 `chrome://extensions`
3. 开启「开发人员模式」
4. 点「加载解压缩的扩展」，选择解压出的 `chrome-mv3` 文件夹

### 权限说明

`tabs` 标签收拢 · `storage` 本地存储 · `alarms` 统计心跳 · `contextMenus` 右键收藏 · `bookmarks` 整理原生收藏 · `history` 访问频率统计 · `unlimitedStorage` 数据存储。所有数据仅存本地，不上传服务器。
