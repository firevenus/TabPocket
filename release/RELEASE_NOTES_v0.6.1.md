# TabPocket v0.6.1 — 新图标

**2026-10-31** · 仅外观改动，无功能变更、无权限变更、无数据结构变更。

## 改了什么

**全新图标**，替换掉项目创建时 WXT 模板自带的那张绿色拼图（那是框架默认占位图，不是我们设计的）。

设计思路：**一张标签页装进口袋**。

- 深绿渐变圆角底板，色系对齐界面主色 `#0f6e56`
- 中间一张近白色标签页，右上错位露出第二张浅绿卡——暗示"装了好几张"，不止一张
- 下方白色口袋，袋口呈**弧形下垂**，让"开口"这件事一眼可读
- 5 个尺寸（16/32/48/96/128）分别渲染，不是拿一张大图缩下去

**关于页的 logo** 也换成了这张图标（原来是 CSS 画的 "TP" 两个字）。

## 怎么改图标

图标源文件是矢量图 `assets/icon.svg`（128×128 画布）。改完后跑：

```bash
python scripts/build-icons.py
```

会重新生成 `public/icon/` 下五个尺寸 + `release/store/icon-512.png`（商店提交用）。
本机没有 ImageMagick / sharp / cairosvg，脚本用 Edge 无头模式渲染，输出带透明通道的 PNG。

## 为什么 16px 单独出图而不是缩放

拿 128px 缩到 16px 会让细边糊成脏点。五个尺寸各自从矢量渲染，小尺寸的边缘才干净。
48/32px 下三层结构（底板 / 卡 / 袋）依然分得清，16px 退化成一个绿块 + 中间浅色块——这是工具栏尺寸下的正常表现，不影响识别。

## 安装

覆盖式更新（保住现有会话、收藏、统计）：

1. 把 `release\TabPocket-v0.6.1\` 里所有文件**复制覆盖**到当前加载的目录
2. `edge://extensions` → TabPocket → **重新加载**
3. 工具栏上的图标会变成新的

⚠️ 因为构建会把 `dist` 目录改名，**每次构建后都必须点一次「重新加载」**，否则后台失联、统计不写入。
